# v1.0.16: Downstream evidence clarification

This release preserves the completed seven-method boundary-reliability analysis and adds a transparent distinction between opposite-sign point estimates and the subset supported by the reported spot-bootstrap intervals.

## Included

- Unit-level classification of all 1,947 downstream feature-settings.
- Method-level frequencies for opposite-sign point estimates and cases in which the reference and at least one opposite-sign alternative both have intervals excluding zero.
- Updated Figure 4 showing both evidence levels.
- A focused S1-S13 supplementary workbook containing only the current cross-method evidence.
- Updated source-data mapping, figure provenance, protocol notes, and reproduction commands.

## Interpretation

The original point estimates are unchanged. Across the five spatial approaches, opposite-sign point estimates occurred in 8.0%-18.5% of evaluable feature-settings. The interval-supported subset occurred in 2.1%-4.5%. These spot-bootstrap intervals remain descriptive because neighboring Visium spots are spatially dependent.
