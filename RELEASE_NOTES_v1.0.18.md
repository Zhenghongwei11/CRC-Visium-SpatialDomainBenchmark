# v1.0.18: Full-13 official calibration and proxy-interface evidence

This release updates the public reproducibility package for the final JBCB R3 submission state after the post-v4 audit cleanup.

## Included

- Full-13 official-implementation sensitivity results for SpaGCN 1.2.7, STAGATE-linked PyG, and BayesSpace nrep=1,000.
- Stability-stratified downstream sensitivity results separating low-, moderate-, and high-ARI settings.
- Molecular tumor-stroma proxy interface results using EPCAM-high and COL1A1/FAP-high inferred domains.
- Updated consolidated supplementary workbook containing S1-S17 Data.
- Cleaned S14-S17 worksheet names and table columns for publication-facing terminology.
- Updated protocol, source-data map, citation metadata, and release-bundle rules.

## Interpretation

The added results support a narrower conclusion than a universal boundary-failure claim. Boundary-dependent downstream sensitivity persists for BayesSpace and SpaGCN in the tested settings, while official-linked STAGATE_pyG is highly stable. The molecular proxy-interface analysis gives a proof-of-principle tumor-stroma consequence test based on expression-derived domains, not independent tissue annotation.
